1. [计算机图形学概述](./work1.md)

- 课程四大主题

2. [向量与线性代数](./work2.md)

- 向量基础
  - 定义：方向 + 长度，无具体起点
  - 归一化：向量除以自身长度，得到单位向量
  - 向量相加：三角形法则 / 平行四边形法则
  - 笛卡尔坐标系：2D (x, y)、3D (X, Y, Z)
- 向量的乘法
  - 点积（dot product）
    - 值 = 两向量长度 × 夹角余弦（标量），满足交换律、分配率、数乘结合律
    - 坐标计算：对应分量乘积之和
    - 应用：求夹角、投影；实践：自动门开门方向判断
  - 叉积（cross product）
    - 结果向量垂直于两向量所在平面，方向由右手定则决定
    - 不符合交换律（交换需加负号）
    - 应用：构造坐标系、判断左/右、判断点是否在三角形内（里/外）
  - 标准正交基与坐标系（orthonormal bases and coordinate frames）

3. [变换（Transformation）](./work3.md)

- 为什么需要变换：模型缩放、3D 世界映射到 2D 屏幕
- 2D 变换
  - 缩放（Scale）：对角矩阵，各轴缩放值；反射矩阵（对应轴 -1）；剪切矩阵（Shear）
  - 旋转（Rotate）：默认绕原点，逆时针为正；代入特殊点推导矩阵
  - 线性变换：缩放、旋转、剪切、反射均属线性变换
- 齐次坐标系（Homogeneous Coordinates）
  - 平移不是线性变换 → 引入齐次坐标（加一维，1 表示点、0 表示向量）
  - 仿射变换 = 线性变换 + 平移，可用一个矩阵表示
  - 有效运算：向量+向量、点-点、点+向量、点+点（中点）
- 逆变换（Inverse Transform）：M 的逆矩阵恢复原状态
- 组合变换（Composing Transforms）
  - 矩阵乘法顺序不可交换（先旋转再平移 ≠ 先平移再旋转）
  - 应用顺序 A1,A2,... → 矩阵乘法 ...A3·A2·A1
  - 分解复杂变换：平移到原点 → 变换 → 逆平移（如绕任意点旋转）
- 3D 变换：同样使用齐次坐标（加一维），仿射变换矩阵特点类似
