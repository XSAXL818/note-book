## UE 射线检测答疑（src/03-ue/sub/06-cpp-02-射线检测.md）

给 `UWorld::LineTraceMultiByObjectType` 做了两次讲解，查证过引擎源码（UE4.23 / UE5.3 一致）：

- `FCollisionQueryFilterCallback::CalcQueryHitType`（`Engine/Source/Runtime/Engine/Private/PhysicsEngine/CollisionQueryFilterCallback.cpp`）：
  ObjectQuery 分支里 `bPreFilter` 时 `return MultiTrace ? Touch : Block`，注释原文 "In the case of an object query we actually want to return all object types ... trick physx by not blocking in the multi case"；非 preFilter 分支才返回 Block（"object query doesn't have the concept of overlap at all"）。
- `UWorld::LineTraceMultiByObjectType`（`Engine/Source/Runtime/Engine/Private/Collision/WorldCollision.cpp`）：调 `FPhysicsInterface::RaycastMulti` 后
  `// object query returns true if any hit is found, not only blocking hit` → `return (OutHits.Num() > 0);`

结论：Multi + ObjectQuery 时命中的每一项都是 touch，即 `FHitResult::bBlockingHit == false`（MultiByChannel 才是"最后一个 bBlockingHit=true，其余为 overlap"）；判断命中应统一用 `OutHits.Num()`。
