## 表格样式重组（贴近原网页视觉）
- 课程大纲已重排成两列（日期 + 主题），用 HTML `<table class="games101-syllabus">` + 内联 `<style>` 块实现自定义样式（字号小一档、灰底表头、行间分隔线）。
- 选择内联 `<style>` 是因为 mdbook 0.5.2 的 `additional-css` 路径解析和 `theme/css/` 自动加载行为有兼容问题，最简单可靠的方式是直接把样式写在 markdown 文件里。
- 期间排查路径问题得出的结论：mdbook 0.5.2 的 `additional-css` 报错时显示的是相对 book 根的路径（如 `assets/games101-syllabus.css`），需配置为 `src/assets/games101-syllabus.css`；但即便如此，CSS 文件也不会被复制到 book 输出（具体原因待查）。`theme/css/custom.css` 同样不被自动复制。`extra-css` / `additional-css` 在 0.5.2 上的行为与官方文档不完全一致，遇到此类需求优先用内联 `<style>`。
