## UE 动画蓝图：线程安全函数是"用属性访问"还是"用缓存的组件引用"

上下文：用户笔记 `src/03-ue/蓝图小记.md`（混合空间 1D 的 Speed 例子）正在对比「属性访问 Property Access」与「初始化时保存角色/运动组件引用」两种取数方式，并追问工作线程上的安全写法。

结论（已答复）：
- 工作线程（BlueprintThreadSafeUpdateAnimation / NativeThreadSafeUpdateAnimation）里**不能**直接用保存的运动组件引用读属性：UObject 非线程安全，存在数据竞争与 GC 悬挂风险；`TryGetPawnOwner()`、`IsValid()` 等也只能游戏线程调用。
- 正确做法二选一：
  1. 用 Property Access —— 引擎在游戏线程阶段求值并复制到 AnimInstance 属性缓冲，工作线程只读副本（Lyra 就是这么做的）；若路径含非线程安全函数，该次访问会被调度回 GameThread 阶段执行。
  2. 自己在游戏线程（NativeUpdateAnimation / PreUpdate）把值读成 POD 存到 AnimInstance 或 FAnimInstanceProxy 成员，线程安全函数里只读这些副本（性能最好，绕过反射）。
- 保存的组件引用（C++ 用 TWeakObjectPtr）只保留在初始化/游戏线程阶段使用。

## mdbook 里怎么写红色字体

用户笔记里用了 `<b color="red">`，但 HTML5 中 `<b>` 没有 `color` 属性（只有已废弃的 `<font color>` 有），所以只加粗不变红。
有效写法：内联 `style`（`<b style="color:#e53935">` / `<span style="color:red">`，mdbook 默认放行内嵌 HTML）；全站方案是 `book.toml` 的 `[output.html] additional-css`（路径相对书根）。当前 book.toml 主题 default-theme = "Ayu"，深色背景下纯 red 偏刺眼，建议用 #e53935 之类。
